# AK2: каталог миров

Ядро в `src/` и общие промпты в `prompts/` меняет разработчик.
Агент адаптирует только knowledge выбранного мира через контролируемые операции.
Доступные миры — существующие непосредственные папки `worlds/*/AGENTS.md`.
Список обнаруживается заново при запуске; отсутствующая папка не выбирается.
Добавление мира не требует изменения Python-кода или этого списка ссылок.

Актуальный список и начальные команды: `./run.sh worlds`.
Runtime передаёт модели каталог из существующих паспортов, а после выбора —
паспорт и knowledge только выбранного мира. Не сохранять здесь имена и описания
конкретных миров: удаление папки должно удалять их из доступного агенту каталога.

Каждый паспорт содержит JSON-блок `world` с описанием и начальной командой.
Все знания, опыт, checkpoints и эксперименты мира должны оставаться в его папке.
Не переносить специфичные знания в общие промпты, каталог или память другого мира.
