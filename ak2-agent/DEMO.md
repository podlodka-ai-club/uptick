# Демонстрация: знание мира и приобретённый опыт

Полный Uptick-прогон под наблюдением уже завершён с uptime 99,5958% за 7 суток.
Для демонстрации используй [итоговый отчёт](worlds/uptick/experiments/supervised-result.md)
и подтверждённый перенос урока между запусками. Это результат разработки с
вмешательствами супервизора; автономность неизменной версии ещё требует проверки.

1. Покажи `AGENTS.md` и паспорт выбранного мира: от человека требуются описание
   и начальная команда. В ядре нет API или стратегии этого мира.
2. Покажи `knowledge/`: эти файлы агент создал самостоятельно через Codex после
   получения паспорта и проверки интеграции. Это инструкция к миру, ещё не опыт.
3. Выполни `memory`: видны условные уроки, основания, подтверждения, противоречия и теги.
4. Запусти новый seed. В `decision.used_memory` видно, какой урок модель применила,
   а `accepted_lessons` показывает, какие выводы ядро приняло по новым фактам.
5. Ограничь запуск одним решением и продолжи через `resume`: мир, план и очередь те же.
6. Запусти `evaluate`: оба агента знают API, но только один получает прошлый опыт.

## Короткая локальная демонстрация

```bash
cd /Users/aigizk/projects/uptick/ak2-agent
./.venv/bin/python worlds/pantry/environment/server.py
```

В другом терминале:

```bash
./run.sh run 'Накорми персонажа в учебной кухне' --seed 21
./run.sh memory --world pantry
./run.sh ask --world pantry 'Какой навык ты приобрёл и какие события это подтверждают?'
./run.sh train --world pantry --seeds 22,23 --jobs 2 --max-steps 12
./run.sh evaluate --world pantry --seeds 201,202 --jobs 2 --max-steps 12
```

Если этот seed уже был обучающим, для evaluate выбери другой. Для чистой истории
сохрани knowledge и начни с новой базы внутри `worlds/pantry/.local/` через `--memory`.
Для демонстрации только без опыта достаточно `run --no-memory`.

## Что уже наблюдалось

Агент сам выбрал кухню по русскому тексту задачи, создал скрипт/скил/промпт,
завершил три запуска (seed 11, 12, 13) и закрепил условный навык приготовления
и приёма пищи. Подтверждения — реальные ответы независимого локального HTTP-сервера.
Во всех трёх запусках: 3 цикла, 6 действий, здоровье 4, success=true.

Парные запуски на seed 101 и 102 тоже все успешны: 6 действий и 2 решения модели
в каждой группе. Значимого изменения поведения или преимущества опыта в этой
простой задаче не продемонстрировано. `used_memory` и рассказ модели показывают
механизм применения опыта, но сами по себе не устанавливают причинный эффект.

[Числа и снимок опыта](worlds/pantry/experiments/results.json) ·
[Ответ агента о своём опыте](worlds/pantry/experiments/memory-answer.md)

После этого проверен JSONL-поток из двух задач (seed 31, 32). Обе завершились
успешно с применением накопленного навыка. [Отдельная трассировка потока](worlds/pantry/experiments/stream-results.json).

На Uptick интеграция также сгенерирована агентом; проверены реальное управление
ресурсами, восстановление и накопление двух уроков, один из которых стал навыком.
Обучающий прогон остановлен по бюджету после 17 решений, парные — после 2 решений
каждый. Это проверка работающего цикла, а не доказательство выполнения недельного SLO.
[Данные Uptick](worlds/uptick/experiments/results.json).

Проверки забывания и противоречий выполняются отдельно тестами с управляемым
возрастом урока. Их нельзя выдавать за спонтанное забывание в этих коротких запусках.
