Подготовь отдельный интерфейс чтения истории остановившегося запуска по приложенному
контракту. world_done указывает, завершён ли мир: при false читать можно только
прошедший участок, без продвижения времени и завершения pending-операций.
Ядро универсально, поэтому протокол и семантику исторических источников
определяешь ты по bootstrap и knowledge этого мира. Не вызывай инструменты Codex.

Верни только files со scripts/history.py и при необходимости references/history.md.
Эти файлы будут установлены в отдельную копию knowledge данного запуска; остальные
скрипты из knowledge доступны для импорта. Не изменяй интеграцию выполнения мира.
Не добавляй стратегию или уроки в эти файлы. Опыт и объяснения прежних решений тебе
не передаются. Если history.py уже есть, исправляй только указанную диагностику.

Не угадывай исторические API. Если документацию можно получить через известный
источник, discover должен проверить её. Если данных недостаточно, верни рабочий
скрипт с discover.status=unavailable и точной причиной; unsupported только при
подтверждённом отсутствии исторических источников. История может быть доступна
частично: перечисли реально документированные источники и их ограничения.
