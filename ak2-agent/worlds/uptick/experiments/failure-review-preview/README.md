# Контексты для разбора сбоев

Эти файлы созданы локально, без вызова модели и изменения опыта.

- [Seed 23](seed-23.json)
- [Seed 67](seed-67.json)
- [Seed 89](seed-89.json)

Планируемый обработчик — Codex SDK, провайдер OpenAI, существующая подписка ChatGPT.
Цель — оценить остановку агента, определить следующую проверку и предложить
обоснованные уроки для памяти выбранного мира. Разбор не выполняет действий в симуляторе.

В контекст входят причина сбоя, рабочий план, знания протокола, выбранные уроки,
последние события и факты выбранного запуска. Секреты из bootstrap и локального
состояния проверены: в контекстах не найдено неотредактированных значений credentials.

При реальном разборе ядро также добавляет факт остановки выполнения с новым числовым
ID памяти и областью agent_execution. Этот факт не означает завершение мира или
доказанную причину серверной ошибки. Предпросмотры не отмечены как выполненный разбор.
