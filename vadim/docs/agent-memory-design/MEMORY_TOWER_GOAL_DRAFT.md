# Goal draft — staged activation of learning memory

Status: approved by the user and activated as the thread Goal on 2026-09-07. No token budget was specified. Existing live-run authorization limits remain in force.

## Objective

Довести универсальную подсистему памяти до проверенного сквозного цикла
«наблюдения → эпизоды → кандидаты → проверенное знание → релевантное извлечение → решение → пересмотр по новым данным».
Поэтапно подключить и донастроить механизмы, предусмотренные архитектурой,
и измерить их вклад относительно уже работающей эпизодической памяти.
Положительный эффект каждого механизма не предполагается заранее.

## Stages and evidence

1. Зафиксировать инвентарь механизмов: реализован, подключён, проверен механически,
   проверен на решениях, полезность подтверждена / не подтверждена / вреден.
   Покрыть рабочую память и файловый handoff, эпизоды, уроки, модель мира,
   playbooks, знания об инструментах, retrieval, consolidation, пересмотр,
   сжатие и forgetting; отдельно отметить декларации без реализации.
2. Начать без среды: на неизменяемых копиях завершённых публичных трасс
   воспроизвести формирование памяти и запросы извлечения. Для каждого этапа
   показать реальные входы, выходы, provenance и причины отказов.
   Проверить недостаточную опору, противоречия, устаревание, несовместимость
   и отсутствие совпадающих условий. Не ослаблять смысл evidence gates ради
   ненулевого числа принятых записей; обоснованные изменения контрактов документировать.
3. Подключать по одному механизму в экспериментальных профилях с учётом зависимостей.
   Проверять прохождение знания до фактического контекста решения, бюджет контекста,
   сохранение после перезапуска и независимое отключение механизма.
   Consolidation сначала dry-run; забывание проверять после появления полезного знания.
4. После офлайн-готовности заморозить обучающий корпус, код, профили и протокол.
   Сравнить эпизодическую память с добавляемыми слоями на новых прогонах,
   при одинаковых модели, доступных наблюдениях и бюджетах. Независимые прогоны
   можно выполнять параллельно, учитывая общие серверные очереди.
   До запуска определить метрики и число повторов в доступных разрешённых лимитах.
   Измерять завершение, uptime, актуальный балл и расходы среды, решения,
   токены, время и использование памяти. Не смешивать расходы среды с ценой LLM.
5. Проверить перенос на вторую ограниченную задачу без изменения ядра памяти.
   Завершить воспроизводимым отчётом и рабочим профилем: для каждого механизма
   обоснованное решение оставить, исправить либо исключить из рабочего профиля.

## Constraints and iteration

- Работать только в vadim/, сохранять чужие изменения, без commit/push.
- Сохранять универсальные интерфейсы; не зашивать ответы симулятора в память или policy.
- Только наблюдаемый опыт: никаких скрытых правил, будущих событий, oracle/evaluation
  ответов в обучающем контексте. Публичные итоги допустимы как явно помеченные исходы.
- Уже просмотренные C/D — development evidence, не новый held-out результат.
- Replay подтверждает механику и retrieval, но не исход неисполненного действия
  и не причинный экономический эффект. Синтетические проверки отмечать отдельно.
- Модель живого агента — Terra medium. Не придумывать новый бюджет или обнулять
  использованные попытки; перед серией сверять журнал разрешённых запусков.
- Делегировать независимые ограниченные задачи. После каждой стадии сохранять
  конфигурацию, измерения, отрицательные результаты и следующий проверяемый вопрос.

## Completion boundary

Goal выполнен, когда инвентарь покрыт, сквозной путь производной памяти работает
на реальном записанном опыте, проведены отдельные проверки полезности и переноса,
а выводы и рабочий профиль воспроизводимы. Одних тестов, включённых флагов или
синтетического успеха недостаточно. Отсутствие положительного эффекта отдельного
механизма допустимо при честной проверке; отсутствие самого сквозного пути — нет.
При непреодолимом дефиците данных, доступа или лимита сохранить доказательства,
точный блокер и необходимый следующий ввод; не объявлять цель достигнутой.
