# Отчёт AK2: сборка и источники

`../ak2-learning-report.html` — автономный файл для передачи жюри: графики,
таблицы, выбранные события и данные встроены внутрь. Интернет требуется только
при переходе по ссылкам на историю симулятора.

`../ak2-learning-report.md` содержит текстовое изложение и краткий ответ для формы.
`../ak2-learning-report.json` — собранная выборка из 24 запусков AK2 с исходными
метриками, серверными результатами, выбранными событиями и следами памяти.

## Повторная сборка из сохранённого JSON

Из корня репозитория uptick, Python 3.10+ без внешних зависимостей:

```sh
python3 reports/tools/build_ak2_learning_report.py \
  --dataset reports/ak2-learning-report.json \
  --out reports
```

Для этой команды не нужны сервер, SQLite агента или временные файлы первого
сбора. Шаблон находится рядом со скриптом: `ak2-learning-report.template.html`.
Нарратив отчёта относится к зафиксированной выборке и указанным четырём run;
при добавлении других запусков выводы и текст необходимо пересмотреть.

## Как получены данные

1. Взяты метрики AK2 из `reports/all-runs-stats.json` проекта HackerSprint2_sim.
2. Через SSH прочитаны свежие серверные сводки всех 24 запусков и полные журналы:
   `i3DeiIf8iN2lkCyDqGy7izYW`, `SSivLkFdZvZ4czmTqQulgE8H`,
   `rDboa9fRjRXAnWz0wBQngks2`, `KfRgiEVUNuTv0SUNlcWOJUgn`.
3. В локальной копии данных четыре журнала пересчитаны исходным
   `cmd/runstats` симулятора. Семантика его счётчиков сохранена.
4. `extract_ak2_facts.go`, помещённый в `cmd/reportfacts` временной копии проекта
   симулятора, извлёк выбранные события через `journal.ScanReadOnly`.
   Команды и пути HTTP агрегированы без заголовков и credentials;
   блокировки firewall разделены по наличию AttackID в начале запроса.
5. Выбранные решения и версии взяты из стабильной локальной копии SQLite
   агента. Для цепочки памяти использован сохранённый артефакт
   `cross-run-memory-use.json`.
6. По каждой из 24 записей проверено совпадение количества доменных событий,
   расходов и статуса со свежей серверной сводкой. Четыре полных журнала
   просканированы без ошибок. Хеши исходников и промежуточных наборов данных
   включены в JSON.

Сбор не продвигал симуляционное время и не менял данные сервера.

## Проверка результата

Проверены число запусков и завершений, балансы расходов, длительности,
последний run, отсутствие секретов, синтаксис JavaScript и отображение в браузере.
В браузере проверены переключение 48/168 часов, завершённые/все попытки,
графики, таблица и отсутствие ошибок JavaScript.

Ограничения исходных метрик диска, DDoS, credentials и различия между
наблюдаемым улучшением и причинным эффектом памяти описаны в самом отчёте.
